Place your video files in this folder.

Required files:
- hero-showreel.mp4 (and/or .webm) — background showreel for the Hero section
- placeholder.mp4 (placeholder, the poster image shows when video is missing)

For each project in src/data/projects.ts, add the video file here
and update the videoSrc field. Naming: use the project slug, e.g. urban-threads.mp4

Video specs:
- Format: MP4 (H.264) + WebM (VP9) for best compatibility
- Portfolio videos: vertical 9:16 aspect ratio
- Hero showreel: landscape 16:9
- Max 10MB per file for fast loading
- Always include a poster image (first frame or branded still)
